# SisiPlus 1.0.1

Модульное расширение Lampa для Android TV. Исходный код Sisi не изменяется и не включён в проект: каждый сайт реализован независимым адаптером с единым контрактом.

## Установка

Самый надёжный вариант — опубликовать содержимое каталога `SisiPlus` на HTTPS-сервере или GitHub Pages и добавить в Lampa один из URL:

```text
https://ВАШ-ДОМЕН/SisiPlus/dist/sisiplus.js?v=1.0.1
```

`dist/sisiplus.js` — готовая однофайловая сборка для телевизора. Модульный вариант для разработки:

```text
https://ВАШ-ДОМЕН/SisiPlus/loader.js?v=1.0.1
```

После установки откройте **Настройки → SisiPlus** и оставьте нужные источники включёнными. В меню Lampa появится пункт **SisiPlus**. Дополнительное подтверждение возраста внутри расширения не требуется.

Для быстрой проверки с компьютера в одной локальной сети запустите `serve.ps1`. Скрипт покажет готовый LAN-URL для Lampa. Окно сервера должно оставаться открытым; постоянную установку лучше размещать на HTTPS.

## Источники

| Адаптер | Каталог | Поиск | Прямое видео | Страна / национальность |
|---|---:|---:|---:|---:|
| Pornhub | Webmasters API | Да | HLS/MP4 | — |
| Xvideos | HTML-каталог | Да | HLS/MP4 | — |
| Xhamster | `window.initials` | Да | HLS | — |
| eFukt | HTML-каталог | Да | MP4 | — |
| BongaCams | `listing_v3` | Да | HLS | По языку/национальной группе |
| Runetki | `listing_v3` | Да | HLS | По языку/национальной группе |
| Chaturbate | официальный Online Rooms API | Да | HLS со страницы комнаты | По ISO-стране модели |
| Stripchat | Models API | Да | HLS | По `modelsCountry` |

У live-адаптеров пункт **Страна / национальность** находится в правом меню списка. Долгое нажатие на карточке также предлагает показать моделей с таким же значением. Stripchat фильтруется сервером по стране. Chaturbate фильтруется по полю `country`. BongaCams и Runetki не отдают подтверждённую страну проживания, поэтому там используется предоставленное площадкой поле языка/национальной группы — интерфейс намеренно не выдаёт его за точную геолокацию.

Если прямой поток временно отсутствует или сайт изменил разметку, плеер пытается открыть страницу видео/комнаты через WebView, Browser API Lampa, Android bridge или системный браузер.

## Архитектура

- `loader.js` — последовательно загружает ядро и адаптеры из manifest.
- `core.js` — реестр адаптеров, меню и компоненты Lampa.
- `api.js` — Android-native запросы, fetch, резервный HTTPS-прокси, JSON и TTL-кэш.
- `adapter-utils.js` — HTML/JSON-парсинг, страны, длительность и общий формат результата.
- `player.js` — выбор качества, запуск Lampa.Player и WebView fallback.
- `ui.js` — карточки, линии, пагинация, поиск, категории и фильтры.
- `settings.js` — настройки плагина и переключатели адаптеров.
- `adapters/live-base.js` — общая реализация сети BongaCams/Runetki.
- `adapters/*.js` — независимые сайты без `if (site === ...)` в ядре.

Обязательный контракт:

```js
class Adapter extends SisiPlus.Adapter {
  getName() {}
  getCategories() {}
  getFilters() {}
  search(query, page, filters) {}
  getList(category, page, filters) {}
  getVideo(id, item) {}
}
```

Удаление записи адаптера из `adapters/manifest.json` не влияет на остальные источники.

## Сетевой транспорт

На Android первым используется `Lampa.Reguest.native`, поскольку он не ограничен browser-CORS. Затем идут обычный `fetch` и резервный прокси. По умолчанию включён публичный прокси из исследованного Cherry Plugin; его можно выключить или заменить в настройках.

Для полностью независимой эксплуатации укажите собственный прокси шаблоном:

```text
https://proxy.example/proxy?url={url}&referer={referer}&key={key}
```

Для Chaturbate используется параметр WM официального affiliate API. Его значение можно заменить в настройках SisiPlus.

## Сборка и проверка

```powershell
cd SisiPlus
npm run check
npm test
npm run test:live
npm run build
```

- `npm test` проверяет синтаксис, регистрацию восьми адаптеров, manifest, общий контракт и загрузчик.
- `npm run test:live` проверяет реальные каталоги и первые байты HLS/MP4. Для BongaCams/Runetki на Windows имитируется Android-native маршрут через `curl`.
- `npm run build` создаёт `dist/sisiplus.js`.

Живые сайты могут менять домены, HTML и защиту от ботов без уведомления. Поэтому каждый адаптер изолирован, ошибки одного источника не останавливают плагин, а WebView остаётся последним резервным путём.

Только для совершеннолетних и только там, где такой контент разрешён законом.
