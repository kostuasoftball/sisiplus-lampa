# SisiPlus beta-1.0.2

> Экспериментальная ветка `codex/beta-1.0.2-player-navigation`. Стабильная версия 1.0.2 в ветке `main` не изменяется.

Модульное расширение Lampa для Android TV. Исходный код Sisi не изменяется и не включён в проект: каждый сайт реализован независимым адаптером с единым контрактом.

## Установка

Каждая пользовательская версия является отдельным полным файлом на GitHub Pages:

```text
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-1.0.0.js
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-1.0.1.js
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-1.0.2.js
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-beta-1.0.0.js
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-beta-1.0.1.js
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/dist/sisiplus-beta-1.0.2.js
```

Последняя ссылка — экспериментальная beta-1.0.2. Она опубликована отдельно и не заменяет стабильную 1.0.2.

Каждый адрес содержит весь код и не зависит от переключателя или дополнительного CDN. Модульный вариант для разработки:

```text
https://kostuasoftball.github.io/sisiplus-lampa/SisiPlus/loader.js?v=1.0.2
```

После установки откройте **Настройки → SisiPlus** и оставьте нужные источники включёнными. В меню Lampa появится пункт **SisiPlus**. Дополнительное подтверждение возраста внутри расширения не требуется.

Для быстрой проверки с компьютера в одной локальной сети запустите `serve.ps1`. Скрипт покажет готовый LAN-URL для Lampa. Окно сервера должно оставаться открытым; постоянную установку лучше размещать на HTTPS.

## Необязательные аккаунты и избранное

Chaturbate и Stripchat поддерживают необязательное подключение уже авторизованной сессии. Логин и пароль расширение не запрашивает и не хранит: современные формы сайтов используют CAPTCHA, CSRF, отпечаток устройства и иногда 2FA.

В **Настройки → SisiPlus** для каждого из двух сайтов доступны:

1. **Добавить или обновить сессию** — вставить полную строку `Cookie` из авторизованного браузера.
2. **Проверить подключение** — серый/жёлтый/зелёный/красный индикатор и текст результата.
3. **Удалить данные аккаунта** — полностью убрать локальную сессию с устройства.

Запросы с Cookie выполняются только напрямую или нативным транспортом Lampa с `proxy: never`: публичный и пользовательский CORS-прокси для них не применяется. JWT Stripchat хранится только в оперативной памяти и автоматически обновляется.

После успешной проверки строка **Избранные модели** появляется над обычными категориями. Chaturbate сопоставляет подписки с официальным Online Rooms API, Stripchat читает онлайн- и офлайн-избранное раздельно. Онлайн-модели идут первыми; офлайн-карточки помечены и не пытаются запускать отсутствующий поток.

Cookie является временным ключом доступа к аккаунту и хранится локально средствами Lampa без системного защищённого хранилища. Рекомендуется отдельный аккаунт без платёжных данных. Без Cookie, при её удалении или истечении все публичные каталоги продолжают работать в гостевом режиме.

Правое меню открывается повторным нажатием **Вправо** на крайней карточке. Оно содержит поиск, сортировку, жанр/тип моделей, особенности источника и **Страну / национальность** для live-адаптеров. Та же панель доступна кнопкой фильтра в верхней строке Lampa. Stripchat фильтруется сервером по стране. Chaturbate фильтруется по полю `country`. BongaCams и Runetki не отдают подтверждённую страну проживания, поэтому там используется предоставленное площадкой поле языка/национальной группы — интерфейс намеренно не выдаёт его за точную геолокацию.

По умолчанию карточка передаётся внешнему плееру, выбранному пользователем в самой Lampa. В **Настройки → SisiPlus → Плеер** можно включить внутренний плеер Lampa. Во внутреннем режиме карточки текущей сетки образуют плейлист: первое нажатие стрелки пульта открывает панель, следующие стрелки перемещают фокус по её кнопкам, а центральная кнопка выполняет выбранное действие. Штатные кнопки «предыдущее/следующее» переключают видео или моделей без возврата в каталог. Долгое нажатие на карточке открывает только выбор внешнего или внутреннего плеера и сразу запускает выбранный вариант.

## Архитектура

- `loader.js` — последовательно загружает ядро и адаптеры из manifest.
- `core.js` — реестр адаптеров, меню и компоненты Lampa.
- `api.js` — Android-native запросы, fetch, резервный HTTPS-прокси, JSON и TTL-кэш.
- `adapter-utils.js` — HTML/JSON-парсинг, страны, длительность и общий формат результата.
- `auth.js` — локальные сессии, проверка состояния и безопасный гостевой fallback.
- `player.js` — выбор внешнего/внутреннего плеера, качества, внутренний плейлист Lampa и ленивое разрешение следующего потока.
- `ui.js` — карточки, линии, пагинация, поиск, категории и фильтры.
- `settings.js` — настройки плагина и переключатели адаптеров.
- `adapters/live-base.js` — общая реализация сети BongaCams/Runetki.
- `adapters/*.js` — независимые сайты без `if (site === ...)` в ядре.

Обязательный контракт:

```js
class Adapter extends SisiPlus.Adapter {
  getName() {}
  getCapabilities() {} // optional: account, favorites
  getCategories() {}
  getFilters() {}
  search(query, page, filters) {}
  getList(category, page, filters) {}
  getVideo(id, item) {}
  validateSession(session) {} // только если account=true
  getFavorites(session) {}    // только если favorites=true
}
```

Удаление записи адаптера из `adapters/manifest.json` не влияет на остальные источники.

## Сетевой транспорт

На Android первым используется `Lampa.Reguest.native`, поскольку он не ограничен browser-CORS. Затем идут обычный `fetch` и резервный прокси. По умолчанию включён публичный прокси из исследованного Cherry Plugin; его можно выключить или заменить в настройках.

Для полностью независимой эксплуатации укажите собственный прокси шаблоном:

```text
https://proxy.example/proxy?url={url}&referer={referer}&key={key}
```

Для Chaturbate используется параметр WM официального affiliate API. Его значение можно заменить в настройках SisiPlus.

## Сборка и проверка

```powershell
cd SisiPlus
npm run check
npm test
npm run test:live
npm run build
```

- `npm test` проверяет синтаксис, регистрацию восьми адаптеров, manifest, общий контракт и загрузчик.
- `npm run test:live` проверяет реальные каталоги и первые байты HLS/MP4. Для BongaCams/Runetki на Windows имитируется Android-native маршрут через `curl`.
- `npm run build` создаёт `dist/sisiplus.js`.

Живые сайты могут менять домены, HTML и защиту от ботов без уведомления. Поэтому каждый адаптер изолирован, ошибки одного источника не останавливают плагин, а WebView остаётся последним резервным путём.

Только для совершеннолетних и только там, где такой контент разрешён законом.
